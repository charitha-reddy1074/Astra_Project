Student Academic Management System
AI-Powered NCERT RAG Academic Platform
Detailed Technical & Functional Documentation
1. Introduction
The Student Academic Management System is an AI-powered educational platform designed to modernize
academic learning and school management using:
RAG (Retrieval-Augmented Generation)
AI-generated quizzes
AI-generated flashcards
Gamified learning
Academic analytics
Multi-role school management
The platform primarily uses NCERT textbooks and custom educational content uploaded by schools to
create intelligent learning experiences for students.
The system transforms static educational materials into:
Interactive quizzes
Flashcards
Performance analytics
Personalized learning experiences
Gamified learning journeys
2. Main Objective of the Project
The main goal of the project is to:
Digitize academic management
Reduce teacher workload using AI
Improve student engagement
Provide personalized learning
Automatically generate educational content
Track student progress continuously
Create a scalable academic ecosystem for schools

11. Document Processing Pipeline
Step 1 — File Upload
The teacher uploads:
NCERT textbooks
Notes
Worksheets
Custom material
Step 2 — Text Extraction
Libraries used:
File Type Library
PDF PyMuPDF/pdfplumber
DOCX python-docx
TXT Native parser
Step 3 — Text Cleaning
Processing includes:
Removing special characters
Removing unwanted spaces
Header/footer removal
OCR cleanup
Step 4 — Chunking
Why Chunking?
Large documents cannot be directly sent to LLMs.

12. RAG Pipeline Architecture
What is RAG?
RAG stands for Retrieval-Augmented Generation.
It helps AI generate accurate educational content using uploaded textbooks.
• 
• 
• 
11
RAG Workflow
User requests quiz generation
        ↓
Relevant chunks retrieved from vector DB
        ↓
Chunks added as context
        ↓
LLM receives context
        ↓
LLM generates accurate educational content
Why RAG?
Without RAG:
AI hallucinates
Generates generic answers
With RAG:
AI uses actual textbook content
Generates syllabus-based output
Improves accuracy
